# 区间翻转排序

**时间限制：** 2 秒  
**内存限制：** 256 MB

## 题目描述

给定一个长度为 $n$ 的排列 $p$（$1 \le p_i \le n$，每个数恰好出现一次）。你可以执行以下操作任意次（包括零次）：

选择两个下标 $l$ 和 $r$（$1 \le l \le r \le n$），将子数组 $p[l \dots r]$ 翻转。

定义 $f(p)$ 为将排列排序为升序 $[1, 2, \dots, n]$ 所需的最少操作次数。

给定 $n$ 和 $k$，求有多少个长度为 $n$ 的排列 $p$ 满足 $f(p) = k$。

由于答案可能很大，对 $10^9 + 7$ 取模输出。

## 输入格式

一行两个整数 $n$ 和 $k$（$1 \le n \le 200$，$0 \le k \le 10$）。

## 输出格式

一个整数——满足 $f(p) = k$ 的排列个数，对 $10^9 + 7$ 取模。

## 样例

### 样例 1

**输入：**
```
3 1
```

**输出：**
```
3
```

**解释：** 长度为 3 的排列中，$f(p) = 1$ 的排列有 $[2,1,3]$、$[1,3,2]$、$[3,2,1]$。例如 $[2,1,3]$ 可以通过翻转 $[1,2]$ 变为 $[1,2,3]$，只需 1 次操作。

### 样例 2

**输入：**
```
4 0
```

**输出：**
```
1
```

**解释：** 只有已排序的排列 $[1,2,3,4]$ 需要 0 次操作。

### 样例 3

**输入：**
```
5 2
```

**输出：**
```
68
```

### 数据范围

- $1 \le n \le 200$
- $0 \le k \le 10$
