题解：星云的引力透镜效应（NebulaLens）

核心观察

总引力势能公式可以分解为 x 和 y 两个独立的部分： $$V(X,Y) = \sum_{i=1}^{n} m_i \cdot |X - x_i| + \sum_{i=1}^{n} m_i \cdot |Y - y_i|$$

对于每个维度，问题转化为：给定若干点及其权重，查询某点的加权绝对距离和。

这是一个经典问题，可以通过排序+前缀和或树状数组/线段树来解决。

算法

将 x 坐标和 y 坐标分别处理。

对于 x 维度： - 维护所有星云的 $(x_i, m_i)$。 - 查询 $X$ 时，需要计算 $\sum m_i \cdot |X - x_i|$。 - 可以将星云按 $x_i$ 排序，使用二分查找找到分界点，然后用前缀和优化计算。

关键实现细节： - 使用离散化处理大范围坐标（$10^9$），将所有出现过的 x 和 y 坐标排序去重 - 使用两个 FenwickTree 分别维护 x 和 y 维度，每个节点存储 (count, sum) - count 记录该位置有多少个点，sum 记录这些点的坐标和 - 查询时通过 lower_bound 找到离散化后的索引位置 - 重要：使用 lower_bound 返回从 0 开始的索引，而不是从 1 开始

计算公式： $$\sum m_i \cdot |X - x_i| = X \cdot (\text{左边点数} - \text{右边点数}) + (\text{右边坐标和} - \text{左边坐标和})$$

复杂度

  • 时间：$O(m \log n)$，每次操作树状数组 $O(\log n)$。
  • 空间：$O(n)$，使用 vector 动态分配。

注意事项

  • 使用 vector 而非全局数组避免栈溢出。
  • 离散化时注意使用 lower_bound 返回正确的索引（从 0 开始）。
  • 修改操作需要先在原位置删除（-1, -coord），再在新位置添加（+1, +coord）。
