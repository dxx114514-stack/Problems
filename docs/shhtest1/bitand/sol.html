题解：星际关税的按位与协议

核心观察

按位与操作 $a_i \leftarrow a_i \& x$ 有一个重要性质：每个 $a_i$ 的二进制表示中，1 的个数只减不增。因此，每个元素最多被修改 $O(\log(\max a_i))$ 次（最多 30 次）就会变为 0 并保持不变。

关键剪枝：维护区间的按位或 OR。如果 (tr[u].orv & x) == tr[u].orv，说明该区间所有为 1 的位在 $x$ 中也都是 1，因此执行 &x 后所有值不变，可以直接跳过该节点。

否则，递归进入子节点。如果到达叶子节点，直接执行按位与并更新。

算法

线段树每个节点维护： - sum：区间和 - orv：区间按位或

update(u,l,r,L,R,x)： - 如果区间 [l,r] 与 [L,R] 无交，返回。 - 如果 (tr[u].orv & x) == tr[u].orv，返回（无需修改）。 - 如果 l == r，直接 a[l] &= x，更新 sum 和 orv，返回。 - 下传到子节点，递归更新。 - pushup 合并。

query：标准线段树区间求和。

复杂度

  • 时间：$O((n + m)\log n \log A)$，其中 $A = 2^{30}$。均摊分析保证每个元素最多被修改 $O(\log A)$ 次。
  • 空间：$O(n)$。
