一、思路推导

  1. 问题模型：节点连通、集合合并、查询连通块数量，标准并查集（DSU）适用场景。
  2. 约束条件：不是所有边都能合并，仅边权 ≤ lim 的边允许连通两个节点。
  3. 执行流程： ① 初始化并查集，每个节点初始自成一个集合； ② 遍历所有边，判断边权是否合法，合法则执行合并操作； ③ 遍历所有节点，统计「根节点」数量，即为连通块总数。
  4. 优化选择：使用路径压缩优化查找效率，适配 1e5 级大数据。

二、算法分析

核心算法：带权值筛选的约束型并查集，基础并查集的场景变形。

三、复杂度分析

  1. 时间复杂度：近似 $O(n + m)$ 路径压缩后，并查集单次 find/union 操作均摊复杂度接近常数；遍历 n 个节点、m 条边。
  2. 空间复杂度：$O(n)$ 仅需并查集父节点数组，大小为 n+1。

四、关键点与易错点

  1. 边筛选：必须先判断 w ≤ lim，不满足直接跳过合并。
  2. 统计规则：只有根节点（find(i) == i）才算一个独立连通块。
  3. 输入规模大：C++ 需关闭流同步加速读写，防止 TLE。
  4. 特殊情况：m=0 时，每个节点都是独立块，答案等于 n。

五、拓展考点

本题可继续升级：增加「按秩合并」优化、多组阈值查询、离线排序边求动态连通块等，是图论入门经典拓展题。
