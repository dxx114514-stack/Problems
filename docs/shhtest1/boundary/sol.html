题解：拓扑绝缘体的边界态

核心观察

将环形序列拆为链，并定义差分数组： $$d_i = h_i - h_{i-1}\quad (i=1\sim n)$$ 其中 $h_0 = h_n$（环形）。

节点 $i$ 是边界态，当且仅当 $(h_i-h_{i-1})$ 与 $(h_{i+1}-h_i)$ 异号，即 $d_i \cdot d_{i+1} < 0$（严格不等）。

对于区间加操作 1 l r x： - 区间内部所有相邻高度差不变； - 只有区间端点处的差分可能改变：$d_l$ 增加 $x$，$d_{r+1}$ 减少 $x$（环形处理下标）。

因此，一次区间加最多影响 $4$ 个位置的边界态属性（位置 $l-1,l,r,r+1$ 及其相邻）。

算法

用 std::set（或布尔数组+计数器）维护当前所有边界态节点的集合。

  • 初始时 $O(n)$ 扫描找出所有边界态。
  • 操作 1 l r x：只检查可能发生变化的位置 $l-1,l,r,r+1$（环形取模），更新 $d$ 数组，重新判断这些位置及其相邻位置是否为边界态，并维护集合。
  • 操作 2：直接输出集合大小。

复杂度

  • 时间：$O(n + m\log n)$，每次修改涉及常数个位置的 set 操作。
  • 空间：$O(n)$。
