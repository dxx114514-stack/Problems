一、思路推导

  1. 问题分析：求最小载重上限，该值存在明确单调性： 载重越大，需要的分组数越少；载重越小，分组数越多。
  2. 算法选型：具有单调性的最值问题，优先使用二分答案。
  3. 二分范围：
  4. 下界：单件货物最大重量（载重不能小于任意一件货物）；
  5. 上界：所有货物总重量（只分一组的情况）。
  6. 校验函数：给定一个载重 lim，用贪心遍历数组，连续累加，超重则新建分组，统计总组数，判断是否 ≤ m。
  7. 二分规则：若当前 lim 合法，尝试更小值；不合法则放大 lim。

二、算法分析

核心算法：二分答案 + 贪心校验，二分经典变形应用题。

三、复杂度分析

  1. 时间复杂度：$O(n \log S)$ n 为货物数量，S 为所有货物总重量。二分次数约 $\log(10^{11}) \approx 37$ 次，每次校验 O(n)，1e5 数据可轻松通过。
  2. 空间复杂度：$O(n)$ 存储货物重量数组，无额外复杂空间。

四、关键点与易错点

  1. 二分左边界必须取最大单件重量，否则直接无解。
  2. 累加和使用 long long，避免大数累加溢出。
  3. 初始分组数设为 1（所有元素至少分为一组）。

五、拓展说明

本题区别于纯模板切木材题，强化了「连续分组+组数限制」的业务场景，是比赛高频变形考点。
