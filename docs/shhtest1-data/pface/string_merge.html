字符合并博弈

时间限制： 2 秒
内存限制： 256 MB

题目描述

Alice 和 Bob 玩一个关于字符串的游戏。给定一个由小写字母组成的字符串 $s$。

两人轮流操作，Alice 先手。每次操作：

  1. 选择两个相邻字符 $s[i]$ 和 $s[i+1]$。
  2. 删除这两个字符，在原位置插入一个新字符，新字符必须是：
  3. $s[i]$ 或 $s[i+1]$，或者
  4. 在字母表中位于 $s[i]$ 和 $s[i+1]$ 之间的某个字母（例如 $s[i]=\text{'a'}$，$s[i+1]=\text{'c'}$，则可选 'a'、'b'、'c'）。

当字符串只剩一个字符时游戏结束，该字符即为游戏结果。

Alice 希望结果尽量小（字典序），Bob 希望结果尽量大。两人都采用最优策略。

求最终结果字符。

输入格式

一行一个字符串 $s$（$1 \le |s| \le 300$）。

输出格式

一个字符——游戏结果。

样例

样例 1

输入：

acb

输出：

a

样例 2

输入：

cba

输出：

a

样例 3

输入：

ab

输出：

a

解释： 只剩两个字符，Alice 必须合并。可选结果为 'a' 或 'b'。Alice 想要最小化，选 'a'。

数据范围

  • $1 \le |s| \le 300$
  • $s$ 由小写英文字母组成
