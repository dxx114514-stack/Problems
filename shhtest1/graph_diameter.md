# 图的直径

**时间限制：** 4 秒  
**内存限制：** 512 MB

## 题目描述

给定一个 $n$ 个节点、$m$ 条边的无向图 $G$。图中可能有重边和自环。

定义顶点 $v$ 的**偏心率** $d(v)$ 为 $v$ 到所有其他顶点的最短路距离的最大值。图的**直径**为 $\max_v d(v)$。

你最多可以执行**一次**操作：选择任意一条边 $(u, v)$，将其权值**加倍**（乘以 2）。

求操作后图的**最小可能直径**。

## 输入格式

- 第一行：两个整数 $n$ 和 $m$（$2 \le n \le 100{,}000$，$1 \le m \le 500{,}000$）。
- 接下来 $m$ 行：每行三个整数 $u_i, v_i, w_i$（$1 \le u_i, v_i \le n$，$1 \le w_i \le 10^9$），描述一条权值为 $w_i$ 的边。

## 输出格式

一个整数——操作后图的最小可能直径。

## 样例

### 样例 1

**输入：**
```
3 3
1 2 1
2 3 1
1 3 3
```

**输出：**
```
2
```

**解释：** 原始直径为 2（路径 1→2→3 权值为 2）。不操作即可达到最小直径。

### 样例 2

**输入：**
```
4 3
1 2 5
2 3 5
3 4 5
```

**输出：**
```
15
```

**解释：** 链状图，原始直径为 15。加倍任何边都会使直径更大或不变。

### 样例 3

**输入：**
```
5 4
1 2 1
2 3 1
3 4 1
4 5 10
```

**输出：**
```
13
```

### 数据范围

- $2 \le n \le 100{,}000$
- $1 \le m \le 500{,}000$
- $1 \le w_i \le 10^9$
- 图连通
