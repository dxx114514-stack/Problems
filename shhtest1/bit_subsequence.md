# 位串回文子序列

**时间限制：** 2 秒  
**内存限制：** 256 MB

## 题目描述

给定一个长度为 $n$ 的二进制串 $s$ 和一个整数 $k$。求 $s$ 的子序列中，满足以下所有条件的个数：

1. 该子序列是**回文串**。
2. 该子序列长度至少为 $k$。
3. 该子序列从最高位开始解释为二进制数后，能被 $3$ **整除**。

由于答案可能很大，对 $10^9 + 7$ 取模输出。

**子序列**是从原串中删除若干字符（可以不删）后，保持剩余字符相对顺序不变得到的串。

## 输入格式

- 第一行：两个整数 $n$ 和 $k$（$1 \le n \le 300$，$1 \le k \le n$）。
- 第二行：一个长度为 $n$ 的二进制串 $s$。

## 输出格式

一个整数——满足条件的子序列个数，对 $10^9 + 7$ 取模。

## 样例

### 样例 1

**输入：**
```
4 2
1101
```

**输出：**
```
3
```

**解释：** 长度 $\ge 2$ 的回文子序列中，值能被 3 整除的有：三个 "11"（分别来自位置 (1,2)、(1,4)、(2,4)），值均为 3。

### 样例 2

**输入：**
```
3 1
111
```

**输出：**
```
3
```

**解释：** "11" 有三个子序列（位置 (1,2)、(1,3)、(2,3)），值为 3，能被 3 整除。"1" 值为 1 不行，"111" 值为 7 不行。

### 样例 3

**输入：**
```
5 3
10101
```

**输出：**
```
1
```

**解释：** "10101" 本身是回文串，值为 21，能被 3 整除，且长度为 5 $\ge$ 3。

## 数据范围

- $1 \le n \le 300$
- $1 \le k \le n$
- $s$ 为二进制串
